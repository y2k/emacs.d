# Emacs configuration

Requires Emacs 29+ and an internet connection for the first launch.

Clone with the Sanemacs submodule:

```sh
git clone --recurse-submodules git@github.com:y2k/emacs.d.git ~/.emacs.d
```

For an existing clone, initialize the submodule:

```sh
git -C ~/.emacs.d submodule update --init --recursive
```

Start Emacs and confirm installation of the selected packages when prompted.
